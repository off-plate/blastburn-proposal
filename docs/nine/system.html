Every token and every component this direction uses, in every state, on one page. It loads the same app.css and mem.css the site loads, so what is below is the shipping component rather than a drawing of it. Change a rule and this page changes.

01   Where this came from

Michael's call, 12 August 2026: the palette is Gold's Gym: warm near-black, one hard yellow, cream. The teal this direction started with is not in their logo. Anton is the club lettering, Epilogue the body. The paper grain over everything is a single fixed SVG element.

Pricing idea: Club membership cards with a stamped approval mark on the one that wins. No other direction uses it.

02   Colour, as roles

A palette is not a system. Each token below says what it means, so a new component has exactly one correct answer. Contrast is computed against the surface the token is actually read on, not eyeballed and not against a ground it never sits on. A surface has no contrast requirement of its own; what sits on it does.

13   The one-edit test

If a change costs more than one edit, the system is wrong and every future request carries the same tax. Answered honestly.

The requestPlaces to edit
Make every primary button red1 — the .bt--y rule in app.css
Change the accent1 — the accent token in :root
Change the body typeface1 — the @font-face and the body rule
Change the page width1 — --shell
Change the page gutter3 — --pad plus its two phone overrides, which is the point of the overrides
Change how a price is set1 per surface it appears on, and it appears on one
